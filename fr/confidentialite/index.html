Confidentialité

Cette page concerne le site syntheo.studio. La confidentialité de l'application Syntheo elle-même est décrite dans la documentation : Données et confidentialité et Syntheo Desktop et le RGPD.

Ce que le site ne fait pas

  • Aucun cookie.
  • Aucune mesure d'audience.
  • Aucune police, aucun script ni aucune autre ressource tierce : tout ce que chargent les pages vient de syntheo.studio.

Ce que garde votre navigateur

Deux choix sont mémorisés dans votre navigateur (localStorage), sans jamais être envoyés au site :

  • la langue, quand vous choisissez EN ou FR (syntheo-lang, assets/js/lang.js) ;
  • le thème, quand vous choisissez clair ou sombre (syntheo-theme, assets/js/theme.js).

Vous pouvez les effacer en supprimant les données de ce site dans votre navigateur.

L'hébergeur

GitHub, qui héberge le site, enregistre l'adresse IP des visiteurs dans ses journaux techniques, pour des raisons de sécurité (documentation de GitHub Pages, en anglais). Voir la déclaration de confidentialité de GitHub (en anglais).

Les liens de téléchargement et les liens vers le code source mènent à github.com, qui voit alors aussi votre adresse IP.
